# Using the studio from VS Code

Copy `tasks.json` into your project's `.vscode/` folder (or merge its task), then open a widget file and run
**Terminal → Run Task → Widget Studio: preview this file**. To bind it to a key, add `keybindings.json`'s entry to your
user keybindings (Ctrl+Alt+W).

The studio watches the file: save in VS Code (Ctrl+S) and the pictures update in the studio window beside it. Nothing
needs reinstalling, and any other editor works the same way.
